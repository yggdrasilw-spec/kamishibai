# 漢字のたび｜音読みと訓読み

小学3年生向けの国語教材です。紙芝居で漢字の伝来をたどり、同じ「山」を「やま」と「サン」と読む理由を考えます。一字、言葉、短い文、音訓が混ざる言葉へ段階的に進みます。

[教材を開く](https://yggdrasilw-spec.github.io/kamishibai/)

## オフラインで使う

[index.html](index.html) を保存し、Chromeで開きます。Chromebookでは「ファイル」アプリから保存したHTMLを開けます。挿絵と普通話の録音がHTMLに入っています。

## 操作

- 「はじめる」を選び、「前へ」「次へ」で進みます。
- 問題で迷ったら「ヒント」、理由を確かめて進むには「いっしょに見る」を選びます。
- 「目じるし」からまとまりを選べます。まとめから紙芝居や練習に再挑戦できます。
- Tabで移動し、EnterまたはSpaceで決定できます。Escで目じるしを閉じます。
- 「読み上げ ON」で日本語の場面を自動で読み上げます。「この場面を聞く」は一度だけ読み上げます。オフラインの日本語音声を使える端末で有効です。
- 紙芝居の「中国語の音を聞く」では、内蔵した普通話の「山」を再生します。
